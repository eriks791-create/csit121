JPG Example

About This Image

This is a picture of the Bradford pear tree (Pyrus calleryana) which I captured on my way to CCBC. I took a picture of it because I thought it looked cool. To my suprise when I researched this tree I found out it is considered an invasive species, how interesting.

Why JPG Format?

This picture of a Bradford pear tree is a good choice for a jpeg file because it is a real life picture I took with lots of colors and details which is good because jpeg files sizes are smaller while retaining quality, which makes the webpage load faster.
