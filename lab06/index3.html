What I Learned

By attempting to make a single-column layout for mobile devices and a multi-column layout for desktop devices, I learned how to make my webpage easier to use on different screen sizes. Using CSS Flexbox made it simple to arrange content side by side on larger screens and stack it vertically on smaller screens. I also learned how media queries can apply different styles based on the device being used. Testing the layout on both desktop and mobile views helped me understand how layouts improve user experience.
